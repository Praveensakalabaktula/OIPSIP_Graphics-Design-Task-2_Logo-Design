# OIPSIP_Graphics-Design-Task-2_Logo-Design
Logo design created for Oipsip Task-2, representing the brand LOOP. The design features a bold, blue ring enclosing a clean, white circle, with a small, white dot breaking the ring to suggest motion and connection. Paired with a modern sans-serif wordmark, LOOP, the logo conveys simplicity and cyclical flow. Designed in Figma with a minimal layout.
